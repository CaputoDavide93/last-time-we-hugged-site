## ✨ What's in here

| | Page | URL |
|---|---|---|
| 🏠 | Home | <https://caputodavide93.github.io/last-time-we-hugged-site/> |
| 🔒 | Privacy policy | <https://caputodavide93.github.io/last-time-we-hugged-site/privacy/> |

The iOS and Android apps open the privacy and contact pages from Settings, and the store listings use the same URLs. They're public identifiers: don't rename the repository or move the pages.

Static HTML and CSS only: no scripts, forms, cookies, analytics or web fonts.

## 📖 Usage

Every sentence on the privacy page must be true of the shipped apps. The technical source is `docs/privacy.md` in the (private) app repository: change the app first, then that file and this page together, with a new effective date, before the store listings.
